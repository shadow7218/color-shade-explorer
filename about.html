About This App

Color Shade Explorer is a free, open-source Progressive Web App (PWA) that lets you explore, pick, and copy any color shade — all from your phone, no PC needed.

Features

  • 🎨 Interactive Color Wheel — tap or drag to pick colors
  • 🖼️ Upload any image and pick colors by tapping on it
  • 📋 One-tap copy of HEX, RGB, and HSL values
  • 🔤 Automatic color name detection (nearest CSS named color)
  • 🌈 Shade variants — lighter, darker, and complementary shades
  • 📱 Install as a PWA — works offline, like a native app
  • ⚡ Modern, smooth UI with responsive design

How to Install on Your Phone

  1. Open this website in Chrome (Android) or Safari (iPhone)
  2. Tap the three-dot menu (Chrome) or Share button (Safari)
  3. Select "Add to Home Screen" or "Install App"
  4. Done! The app will appear on your home screen and work offline.

How to Deploy (Free, No PC)

  1. Go to github.com and create an account (free)
  2. Create a new repository named color-shade-explorer
  3. Upload each file (copy-paste the code into the file editor on GitHub)
  4. Go to Settings → Pages → Source: main branch / root folder
  5. Wait 2 minutes — your app is live at yourusername.github.io/color-shade-explorer
